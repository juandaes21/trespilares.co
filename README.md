# Tres Pilares

Sitio web oficial de **Tres Pilares — Planificación Patrimonial**.

## Identidad

**Protege · Construye · Proyecta**

Tres Pilares integra protección, inversión y planificación bajo una visión patrimonial de largo plazo.

## Estructura

- `index.html` — landing principal.
- `assets/css/styles.css` — sistema visual, responsive y animaciones.
- `assets/js/main.js` — navegación, menú móvil, reveals y formulario demo.
- `assets/images/` — reservado para fotografías, logo, favicon y recursos gráficos.
- `.nojekyll` — permite servir el sitio estático sin procesamiento de Jekyll.

## Desarrollo local

No requiere build ni dependencias. Puedes abrir `index.html` directamente o levantar un servidor estático.

## Pendientes antes de producción

1. Reemplazar placeholders del equipo por fotografías reales.
2. Añadir logo/favicon definitivos.
3. Conectar el formulario con LeadConnector / GoHighLevel o agenda.
4. Configurar dominio y analítica.
5. Revisar textos legales y privacidad antes de capturar leads.

## Marca

Tres Pilares es la marca principal. **Plan a Tres** funciona como espacio de contenido y educación dentro de la marca.
